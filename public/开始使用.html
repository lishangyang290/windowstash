WindowStash

保存浏览器窗口，需要时继续。

01

准备 Supabase

  1. 创建自己的 Supabase Project。
  2. 打开 Supabase Dashboard → SQL Editor。
  3. 执行安装包中的 schema.sql。
  4. 在 Project Settings → API 中找到 Project URL 和 Publishable Key。
请只使用 Publishable Key不要使用 service_role key 或任何 Secret Key。
02

连接 Chrome 扩展

  1. 回到 WindowStash 配置页面。
  2. 填写 Supabase Project URL 和 Publishable Key。
  3. 点击“测试连接”，看到“✓ 连接成功”后点击“保存并继续”。
  4. 使用自己的账号注册或登录。
03

安装 Chrome 扩展

  1. 打开 Chrome，在地址栏输入 chrome://extensions。
  2. 打开右上角“开发者模式”。
  3. 点击“加载已解压的扩展程序”。
  4. 选择安装包中的 Chrome Extension 文件夹。
  5. 建议将 WindowStash 固定到浏览器工具栏。
04

安装 WindowStash Companion

  1. 将 WindowStash Companion.app 拖入 macOS“应用程序”。
  2. 打开 Companion，填写与扩展相同的 Supabase 配置。
  3. 使用和 Chrome 扩展相同的账号登录。
第一次打开时当前测试版尚未进行 Apple notarization。如果 macOS 阻止打开，请在 Finder 的“应用程序”中找到 WindowStash Companion，右键选择“打开”，再确认“打开”。
05

保存第一个 Workspace

点击浏览器工具栏中的 WindowStash，可以保存当前状态、保存并关闭窗口或管理工作区。

一个 Chrome 窗口 = 一个 Workspace
06

从菜单栏打开 Workspace

  • 点击 macOS 菜单栏中的 WindowStash 图标并选择 Workspace。
  • 窗口已经打开时，WindowStash 会切换到现有窗口。
  • 窗口未打开时，WindowStash 会恢复该窗口。
07

关于大量标签页

如果 Workspace 有很多标签页，WindowStash 不会一次加载所有网页。未使用的标签页会保持休眠，点击时才会加载。

FAQ

常见问题

为什么恢复后有些页面没有立即加载？

为了避免大量标签页同时占用内存，WindowStash 会在你点击标签页时再加载网页。

为什么 Companion 第一次打不开？

当前测试版暂未进行 Apple notarization。请在 Finder 的“应用程序”中右键 WindowStash Companion 并选择“打开”。

为什么 Chrome 提示这是开发者模式扩展？

当前版本还没有发布到 Chrome Web Store，因此使用 Chrome 官方提供的“加载已解压的扩展程序”方式安装。
